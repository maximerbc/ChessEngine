# Three-minute demo walkthrough

1. **Question (20 seconds):** "Does outcome-based self-play improve a supervised position evaluator under a fixed search budget?" State the actual evidence level shown on the site.
2. **Play (40 seconds):** Choose the supervised model, make a move, and explain the distinction between evaluation and search. Point out depth, nodes, principal variation and model ID. The move is produced by our shared engine.
3. **Compare (40 seconds):** Analyze the same position with supervised and RL models. Discuss one concrete changed decision; do not call a changed decision an improvement without evidence.
4. **Research (60 seconds):** Show training curves, match score and paired uncertainty, and replay a win, loss or draw. Explain held-out openings, reversed colors, and why loss alone is insufficient.
5. **Limitations (20 seconds):** Discuss compute, draw-heavy self-play, seed variance and whether the evidence is positive, negative or inconclusive. Link the report and downloadable inference models.

If the server is waking, begin with the static research page and saved game replay. This still demonstrates the project without hiding the cold start.
